2.3 (28/10/2026)

* Fixed OpenGL rendering on GTK3 and Qt5/Qt6 by rendering on the main thread (`MPVGL_MAINTHREAD`); other platforms keep the render thread.
* Fixed black video on GTK3 by disabling the depth buffer and resetting GL state before each render.
* Fixed GTK3 rendering after moving the video panel to another form by recreating the render context.
* Fixed GTK3 embedded-mode crashes (`X11 BadWindow`) by stopping mpv before destroying the native window and restarting it on Play.
* Fixed Linux OpenGL function loading for EGL and GLX contexts.
* Improved GTK3/Qt rendering updates, responsiveness, and callback cleanup.
* Improved OSD and subtitle scaling with fractional font sizes.
* Added `InvalidateOverlayText` to resend overlay text when OSD metrics change.
* Reduced playback stutter by updating the subtitle overlay only when its text changes.

2.2 (26/10/2026)

* Added `MPVPlayer.Extended.pas`, providing additional APIs for subtitle styling, video color adjustments, deinterlacing, cache configuration, audio output devices, audio normalization and stream information.
* Added optional SMPTE timecode support through the `ENABLE_SMPTE` compiler directive.
* Added frame-based seeking with `SeekInFrames`, `SeekInSecs`, `SeekInPercent` and `SeekTo`, including exact seeking and keyframe-based seeking.
* Added current-frame and media-duration queries through `GetCurrentFrame`, `GetMediaLenInSecs` and `GetMediaLenInFrames`.
* Improved frame stepping by introducing `StepFrames` and using frame-based calculations for next-frame and previous-frame navigation.
* Fixed startup option handling in `AddOption`: option names are now correctly extracted before `=`, preventing duplicate options from accumulating instead of updating existing values.
* Improved OSD and subtitle sizing by recalculating their metrics when the video is reconfigured or the preview control is resized.
* Added optional video resize notifications through `OnVideoResize`, controlled by the `ENABLE_EXT_EVENTS` compiler directive.
* Added optional playback status notifications through `OnStatusChange`, with states for idle, loading, playing, paused, buffering, end of file, stopped and errors. This feature is controlled by `ENABLE_EXT_STATUS`.
* Added an optional 10-band audio equalizer with adjustable gain, presets, preamp and enable/disable functionality, controlled by `ENABLE_EXT_EQUALIZER`.
* Improved track retrieval error diagnostics by adding exception logging in debug builds.
* Improved macOS OpenGL rendering thread stability by introducing autorelease pools and safer render-context cleanup.
* Improved OpenGL renderer shutdown by replacing the indefinite thread wait with a bounded wait, reducing the risk of application freezes during shutdown.
* Added GTK3 and Qt5/Qt6 conditional support for obtaining the native video window handle, while retaining GTK2 support.
* Updated GTK2 widget realization checks to use `GTK_WIDGET_REALIZED` instead of the unavailable `gtk_widget_get_flags` approach.

2.1 (17/09/2026)

* Refactored the player architecture by introducing the new `TMPVCore` class, separating libmpv playback and event management from the visual `TMPVPlayer` control.
* Moved libmpv initialization, shutdown, commands, properties, playback, tracks, filters, OSD, screenshots and event handling into `TMPVCore`.
* Added the `TMPVPlayer.Core` property for direct access to the underlying libmpv core.
* Preserved the existing `TMPVPlayer` playback API through compatibility wrapper methods that delegate to `TMPVCore`.
* Moved libmpv event handling to a dedicated `TMPVEventThread` owned by `TMPVCore`.
* Improved libmpv and renderer shutdown synchronization, including explicit thread wake-up, termination and cleanup.
* Improved OpenGL renderer thread lifecycle and synchronization with a dedicated ready event.
* Improved OpenGL context destruction safety when the control is being destroyed or its native handle is no longer available.
* Improved SDL2 renderer thread ownership and shutdown handling.
* Added raw screenshot capture to `TBitmap` through `GetScreenshotToBitmap`.
* Improved resize handling by avoiding redundant OSD/subtitle property updates.
* Increased the default playback position update frequency from 140 ms to 33 ms.
* Added Linux Wayland detection with automatic fallback from embedding to OpenGL rendering.
* Added macOS Cocoa layer support through `NSView.setWantsLayer`.
* Added macOS Metal capability detection and platform-specific renderer configuration.
* Added platform-independent window handle retrieval through the new `GetWID` implementation.
* Added `TMPVCore` to the registered Lazarus components.
